# kwtool

Windows 桌面网络核查框架。左侧是批次控制面板，右侧使用可见的 Google Chrome。

## 运行

要求 Python 3.11+ 和已安装的 Google Chrome。建议在 `kwtool` 目录内创建虚拟环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e '.[dev]'
python launcher.py
```

使用时，在左侧每行输入一个主体，选择网站，点击“查询”。程序依次处理并保存 PDF。“停止”会在当前浏览器操作结束后终止批次。界面显示进度和状态，常规运行日志写入 `%LOCALAPPDATA%\kwtool\.log\kwtool.log`。勾选“开发者模式”后，网站适配器会记录详细状态，并可通过 `context.capture_diagnostic(label, page)` 将截图、页面文字和元素结构保存到 `%LOCALAPPDATA%\kwtool\.log\diagnostics\`。诊断文件不保存网址查询参数的值，可能包含网页上显示的主体和查询结果，请按需分享。

主体后可用方括号附加查询参数，例如 `张三[身份证:350100198005060012]`。圆括号始终视为主体名称的一部分，因此 `容诚会计师事务所（特殊普通合伙）` 会原样查询。

选择“企信网”后，程序会在右侧 Chrome 搜索每家企业、依次加载详情栏目、按输出模板加 `_网站.pdf` 后缀保存网页 PDF，并通过网站发送邮件报告。首次访问会等待网站的环境检查；页面出现登录入口时，会提示用户在 Chrome 中登录。搜索和发送报告时出现的验证码由用户手动完成。搜索没有唯一完全匹配项时，在右侧网页点击正确的企业。PDF 已保存但邮件未获网站成功提示时，该行记为失败并继续下一家，已保存的 PDF 不会删除或自动重发邮件。在“网页专属配置”中勾选“批次结束后从 163 邮箱保存报告”后，程序会在批次结束时使用已打开的 163 邮箱，或打开邮箱供用户登录；随后进入收件箱，核对发件人 `gsxt@samr.gov.cn`、企业名称、邮件时间和 PDF 附件名，并校验报告 PDF 的创建时间不早于本次点击发送的时间，按输出模板加 `_导出报告.pdf` 后缀保存附件。邮件尚未到达时会按专属配置中的“163 邮箱刷新间隔”自动刷新（默认 15 秒，可设 5～300 秒），最多等待 10 分钟；期间可点“停止”。找不到可确认的邮件或附件时会在批次结果中列出，且不会保存旧邮件。此选项默认关闭。企信网初始打印设置为 A4 纵向、35% 缩放、打印背景，可在“网页专属配置”中调整。

选择“信用中国”后，程序会搜索企业并等待用户在 Chrome 中填写验证码。搜索结果有唯一完全匹配项时自动进入详情页，否则由用户在右侧网页选择。专属配置中可勾选八个信息板块，默认选择行政管理、严重失信和经营异常；程序逐页打印所选板块并合并为 `_网站.pdf`，随后点击“下载信用信息报告”保存为 `_导出报告.pdf`。初始打印设置为 A4 纵向、35% 缩放、打印背景，页眉页脚与浏览器打印效果一致。网站加载缓慢时会等待请求结束和页面内容稳定。

选择“财政部”后，程序对每个主体搜索财政部全文内容，按时间从新到旧排序，保存第 1 页结果为 PDF。初始打印设置为 A4 纵向、35% 缩放、打印背景。

选择“上海证券交易所”后，可在“网页专属配置”中选择精确搜索或模糊搜索，并勾选全部、公告、规则、监管、新闻中的一个或多个栏目。“关键词”默认是“处罚 行政监管 责令改正 警示函”，用一个或多个空白字符分隔；相同词只搜索一次。程序分别检索“主体 关键词”，在每个勾选栏目导出前 K 个搜索结果页，并按关键词、栏目、页码顺序合并为每个主体的一份 PDF。清空关键词可恢复只检索主体。默认选择模糊搜索、“全部”栏目和前 1 页，打印缩放为 35%，包含浏览器样式的页眉与页脚。上交所没有在搜索指南中说明可靠的“或”检索语法，因此逐词检索以避免合并查询漏掉结果。

选择“百度”后，可在“网页专属配置”填写通用关键词（默认留空）。程序按“通用关键词 主体 关键词”逐词搜索；例如通用关键词为 foo、主体为 a/b/c、关键词为 bar baz 时，依次搜索 foo a bar、foo a baz、foo b bar、foo b baz、foo c bar、foo c baz。关键词以空白字符分隔，默认“立案 调查 监管 处罚”。每个关键词通过百度搜索框提交，并导出前 K 个搜索结果页，默认 K 为 2，并按关键词和页码顺序合并成每个主体的一份 PDF；若没有后续页码或下一页内容重复，则提前停止。翻页时实际点击百度页码；若当前页的页码栏缩短，会返回首页点击首页提供的页码。搜索出现验证页时，请在右侧 Chrome 手动完成，程序会等待结果出现后继续。普通搜索结果加载并稳定后即可打印，不等待文心一言完成生成。默认打印缩放为 35%，包含浏览器样式的页眉与页脚。

百度专属配置中的“翻页稳定时间”和“结果稳定时间”均以秒为单位，可在 0.25～5.00 秒之间调整，默认都是 0.75 秒。前者要求目标页码持续选中后再继续，后者要求普通搜索结果和页码链接保持稳定后再打印。缩短等待可加快搜索，但页面加载较慢时可适当调高。

选择“市场监管行政处罚文书网”后，程序会在每次查询前点击网站的“清空检索条件”，再按“当事人名称”检索并保存第 1 页结果。连续查询时不会叠加上一主体的筛选条件。默认打印缩放为 35%，包含浏览器样式的页眉与页脚。

新增的全国站点选项包括中国裁判文书网、生态环境部、应急管理部、国家市场监督管理总局、国家发展改革委、国家税务总局、中央纪委国家监委、12309 中国检察网及资产证券化分析网。每项输入主体名称后尝试在该站检索并打印搜索结果。网站登录、验证码等步骤仍需在右侧 Chrome 中人工完成；程序无法确认检索结果时会报告失败，不会把站点首页保存为查询结果。生态环境部、发改委和市场监管总局使用已找到的官方检索链接；12309 使用官网全站搜索，在自动化浏览器中曾被其安全防护拦截，需用右侧可见 Chrome 现场验证。资产证券化分析网会先等待用户登录，再搜索主体并切换到“机构”分类；有机构结果时打开首条详情，无匹配时保存机构数量为 0 的搜索页。

选择“人民法院案例库”后，程序先打开首页，等待用户在右侧 Chrome 登录。页面显示已登录用户名后，程序按主体进行全文检索，等待新标签页的检索响应及结果列表加载，再将第 1 页结果保存为 PDF。检索失败或登录失效时不会保存 PDF。默认 A4 纵向、35% 缩放，包含浏览器样式的页眉和页脚。

“完成首次备案的证券评级机构名录”和“从事证券服务业务会计师事务所备案名录”是两个独立选项。程序打开证监会备案结果公示栏目的最新同名公告，保存公告 PDF、原始名单附件及逐主体的 `_核对结果.txt`。DOCX、XLSX 附件按文本核对主体名称；旧 XLS 或无法解析的附件标为“无法判定”。“未命中”仅表示该次公告附件中未找到该名称，不代表不存在其他备案或历史记录。所有新增网页 PDF 默认 A4 纵向、35% 缩放、打印背景，含时间和网站名称页眉及网址和页码页脚。

默认输出模板为 `Output/[date]/[id]-[object]-[website].pdf`。相对路径基于用户“文档/kwtool”；支持 `[date]`（YYMMDD）、`[time]`（HHMMSS）、`[year]`、`[month]`、`[day]`、`[hour]`、`[minute]`、`[second]`、`[id]`（批次序号）、`[object]`（查询主体）、`[website]`（网站名称）。绝对路径也可使用。已有文件会自动增加 `_2`、`_3` 等后缀。Chrome 专用资料保存在 `%LOCALAPPDATA%\kwtool\chrome-profile\cdp`，界面设置保存在 `%APPDATA%\kwtool\settings.json`。程序默认自行启动独立 Chrome，再通过本机调试端口连接。

如需单独验证 Chrome 的启动和连接，可以手动启动独立 Chrome，再让 kwtool 连接。先关闭 kwtool，在 PowerShell 中执行以下命令，并保持 Chrome 窗口打开：

```powershell
$chrome = "$env:ProgramFiles\Google\Chrome\Application\chrome.exe"
$profile = Join-Path $env:TEMP ("kwtool-cdp-" + [guid]::NewGuid().ToString("N"))
& $chrome --user-data-dir=$profile --remote-debugging-address=127.0.0.1 --remote-debugging-port=9229 https://www.gsxt.gov.cn
```

在这个 Chrome 中确认网页可访问后，另开一个 PowerShell 窗口启动 kwtool：

```powershell
cd D:\Projects\prj_kwtool\kwtool
$env:KWTOOL_CDP_URL = 'http://127.0.0.1:9229'
.\.venv\Scripts\python.exe launcher.py
```

连接模式只接受本机调试地址；关闭 kwtool 不会关闭手动启动的 Chrome。此模式使用独立的临时资料夹，不读取日常 Chrome 资料。

## 新增网站

在 `kwtool/adapters/` 新建 `SiteAdapter` 子类，实现 `run_one(context, subject)`，并在 `kwtool/adapters/__init__.py` 的 `registered_adapters()` 中注册。适配器通过 `settings_schema` 声明网站专属设置；打印设置可能因网站而异，应由对应适配器处理。`context.page` 用于浏览器操作，`context.wait_until(ready, message)` 可根据网站状态检测验证码完成后自动继续，`context.save_pdf()` 和 `context.save_download(download)` 用于保存结果。`kwtool.diagnostics.browser_snapshot()` 可记录脱敏后的标签页状态，`context.capture_diagnostic(label, page)` 可在开发者模式保存页面证据。长流程应定期调用 `context.check_stop()`。

## 测试和打包

```powershell
python -m pytest
.\build.ps1
```

`build.ps1` 生成 `dist/kwtool/kwtool.exe` 及其依赖文件。它是可分发的目录版 EXE，运行设备仍需安装 Google Chrome；安装器将在后续阶段制作。打包后应在允许启动 Chrome 的 Windows 桌面环境中完成演示流程的端到端检查。

## 发布与更新

使用 [Jane-JWang/kwtool](https://github.com/Jane-JWang/kwtool) 的正式 Release 分发 Windows 目录版。打包脚本默认使用这个仓库；在仓库根目录运行：

```powershell
cd kwtool
.\build.ps1
```

将 `dist/kwtool-windows.zip` 上传为 Release 附件，保持文件名不变。标签使用 `v0.2.0` 这样的三段数字版本号。每次发布都要同步更新 `pyproject.toml` 和 `kwtool/__init__.py` 的版本。程序通过 GitHub Releases API 列出正式版本，验证附件的 SHA-256 后安装。历史版本可从“回滚”选择。源码运行时只能查询版本；安装和回滚需要使用打包后的 EXE。安装目录及其父目录必须可写。
